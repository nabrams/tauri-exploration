# Open this folder in Android Studio

To get **Gradle sync** and **module selection** (app, tauri-exploration) working:

1. In Android Studio: **File → Open**
2. Select **this folder**: `tauri-exploration/src-tauri/gen/android`
3. Click **Open**
4. Use **File → Sync Project with Gradle Files**

Do **not** open the repo root (`tauri-exploration`) — open `gen/android` so the Gradle project root and modules are detected correctly.
